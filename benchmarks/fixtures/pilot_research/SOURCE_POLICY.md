# Frozen primary-source policy

The source snapshots in `sources/` were checked against the linked official
Python 3.14.6 documentation on 2026-07-21. Treat only those official Python
documentation URLs as decision evidence. The snapshots are concise factual
indexes, not additional authorities.

Do not substitute blogs, search-result pages, package indexes, or documentation
for another Python version. Preserve the exact source URL for every material
claim and disclose any caveat that prevents an unconditional recommendation.
